# Modrinth

<mark style="color:$info;">##dodać zdjęcia aby tuto był kompletny ale czekamy na paczke</mark>

{% hint style="info" %}
Konto Minecraft jest wymagane aby używać aplikacji Modrinth.
{% endhint %}

{% stepper %}
{% step %}
### Krok 1: Pobierz Aplikacje Modrinth (Jeśli Już Jej Nie Masz)

* Idź na oficjalną strone [Launchera Modrinth](https://modrinth.com/app)
* Kliknij przycisk Download dla twojego systemu (**Windows**, **macOS**, **Linux**).
* Odpal zainstalowany Instaler oraz podążaj za krokami instalacji aplikacji Modrinth.
{% endstep %}

{% step %}
### Krok 2: Ogarnij Minecraft'a ig

* Otwórz aplikacje Modrinth.
* Kliknij zakładkę Minecraft jeśli nie jest zaznaczona automatycznie.
* Podążaj za instrukcjami aplikacji aby zalogować się na konto Minecraft.
{% endstep %}

{% step %}
### Krok 3: Znajdź i Zainstaluj paczkę PokeGoGo

* Kliknij wyszukiwanie i wpisz "PokeGoGo".
* Jak już znalazłeś kliknij "Install".
* Po zainstalowaniu paczki powinna się ona znajdować po lewej stronie albo w zakładce "Home" oznaczoną znakiem "▷".
{% endstep %}

{% step %}
### Krok 4: Odpal Gre

* Wysztko by z nami zagrać jest już gotowe.
* Kliknij Play w zainstalowanej paczce aby włączyć grę.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Rekomendujemy przydzielenie co najmniej 4gb RAMU aby zagrać\
Można to zmienić w **Modrinth App Settings > Java > Memory**.
{% endhint %}
